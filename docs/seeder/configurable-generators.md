# Configurable Generators

The following generators support additional configuration options:

| Generator ID     | Configuration Options | Description                                                               | Default Value           |
|------------------|-----------------------|---------------------------------------------------------------------------|-------------------------|
| `random.integer` | `min`, `max`          | Defines the minimum and maximum values for the generated integer          | (-1000, 1000)           |
| `random.decimal` | `min`, `max`          | Defines the minimum and maximum values for the generated decimal          | (-1000, 1000)           |
| `random.text`    | `min`, `max`          | Controls the minimum and maximum length of the generated text             | (1, 10)                 |
| `range`          | `min`, `max`          | Controls the minimum and maximum length of the generated range            | (min, max) are required |
| `byte_array`     | `size`                | Controls the size of the generated byte array                             | 32                      |
| `predefined`     | `distribution`<br>`values` | Controls the order picking values (SEQUENTIAL or RANDOM)<br>List of values to be used | SEQUENTIAL<br>Empty array |

Example configurations:

```yaml
<entity_name>:
  count: 10
  attributes:
    # Integer with range
    <attribute_name_one>:
      generator: random.integer
      min: 18
      max: 65
    <attribute_name_two>:
      generator: byte_array
      size: 20
    <attribute_name_three>:
      generator: predefined
      values: [1, 2, 3]
      distribution: RANDOM    
```
